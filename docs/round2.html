Optional AI polish: a BYO-key assistant (Groq/OpenAI-compatible) rewrites a flagged sentence. The key stays in the browser; the deterministic rules remain the source of truth. Output is clearly marked AI-generated · review before use and never silently replaces the reviewed draft.

Agent Architecture (MVP Scope)

What "agent" means here: the review loop — it selects relevant rules, runs deterministic and contextual checks, produces structured findings, proposes fixes, records human decisions, and (optionally) uses accepted terminology preferences in later scans. Autonomy is intentionally limited to preserve human control.

Check types — reliability is surfaced, not hidden

TypeExamplesReliabilityUI badge
DeterministicBanned phrases, required disclaimers, exact terminology, color hex, date/cert expiryHigh — exact match against a configured ruleRule match
Advisory (LLM+RAG)Tone alignment, clarity, inclusivity, fair-language heuristicsContext-dependent; can miss / inventAI assessment — verify
Honest boundary: the tool never says "compliant" or "approved". It only reports "no deterministic violations found; X advisory items flagged for review". It is a pre-screening aid, not a compliance guarantee.

Known Limitations (Honest Boundaries)

  • Language: English only in this build.
  • Rule quality: demo packs are hand-curated; production PDF→JSON extraction is post-hackathon.
  • Scanned PDFs: not supported in MVP (no OCR yet); selectable-text PDFs work.
  • Logo checks: file-quality heuristics only — not approval of an approved brand asset.
  • AI polish: optional and BYO-key; a fluent rewrite can still violate a rule, so output is re-checkable and human-reviewed.
  • Scope: pre-screening aid only — does not replace MLR, legal, regulatory, or accessibility approval.

Three meaningful Round 3 improvements

  1. Multimodal document & asset review — OCR, page-level evidence, approved-logo matching, accessibility checks. Proof: a scanned document produces a finding linked to the exact page/region.
  2. Enterprise governance & audit — real auth, role-based permissions, isolated workspaces, versioned rules, auditable approval history. Proof: an unauthorized user cannot access another company's workspace.
  3. Controlled publishing & quality measurement — approval-before-publishing, audit trails, false-positive / reviewer-override metrics. Proof: unapproved content cannot publish.
